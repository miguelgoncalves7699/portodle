# Fotografias dos jogadores

Coloca aqui uma fotografia por jogador, em JPG, com o nome exato indicado na primeira coluna.
O jogo associa cada ficheiro ao jogador pelo campo `slug` da base de dados (em `index.html`, constante `P`).

- Formato recomendado: retrato 4:5 (por exemplo 400×500 px), com o rosto no terço superior.
- Se um ficheiro faltar, o jogo mostra as iniciais com a etiqueta **"Foto por adicionar"**.
- Para usar outro nome ou formato num jogador, preenche o campo `"photo"` desse jogador
  (por exemplo `"photo":"assets/players/deco-2003.png"`). Quando `photo` é `null`, usa-se `<slug>.jpg`.
- Usa apenas fotografias que tenhas autorização para publicar.
