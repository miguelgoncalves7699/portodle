# Fundo: Estádio do Dragão

Coloca aqui a fotografia com o nome `estadio-do-dragao.jpg` (paisagem, pelo menos 1920×1080 px, até ~500 KB).
É aplicada em ecrã inteiro (`background-size: cover`) com um overlay azul-escuro para manter a leitura.
Enquanto o ficheiro não existir, aparece a ilustração original de estádio.
Para usar outro nome, altera `ASSETS.stadium` no início do script em `index.html`.
Usa uma fotografia tua ou com licença que permita a publicação.
