# Emblema do clube

Coloca aqui o emblema com o nome `fc-porto-logo.png` (PNG com fundo transparente, pelo menos 256 px de altura).
O jogo mantém as proporções (`object-fit: contain`) e mostra o emblema com 58 px de altura no cabeçalho.
Enquanto o ficheiro não existir, aparece o escudo gráfico genérico.
Para usar outro nome ou formato (por exemplo SVG), altera `ASSETS.clubLogo` no início do script em `index.html`.
O emblema é marca registada do FC Porto: confirma que tens autorização antes de o publicar.
